Game Library

Free homebrew games shared by their authors — tap Play and the game starts right here. No downloads, no installs.

Every library game is homebrew released for free by its author under the license shown on its card. RetroPlay does not include commercial ROMs — to play your own games, use Select Game above and load a ROM file you own.

How to play

  1. Tap Play on any game in the library — or tap Select Game to load your own ROM file (.nes, .gba, or a .zip containing one).
  2. On phones, the touch gamepad appears automatically. On desktop, use the arrow keys + Z / X / Enter / Shift.
  3. Use the player menu (bottom bar) for save states, screenshots and full screen.
RetroPlay does not include any commercial games. Only load ROM files that you own and have the right to use.
