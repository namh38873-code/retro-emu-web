RETROPLAY

Play your own retro games right in your browser. No downloads, no installs.

NES supported
GBA supported
Touch controls
Save states

How to play

  1. Tap Select Game on the player screen (or drag & drop a file onto it).
  2. Pick a ROM file from your device: .nes for NES, .gba for Game Boy Advance. Zipped ROMs (.zip) work too.
  3. On phones, the touch gamepad appears automatically. On desktop, use the arrow keys + Z / X / Enter / Shift.
  4. Use the player menu (bottom bar) for save states, screenshots and full screen.
RetroPlay does not include any games. Only load ROM files that you own and have the right to use.
